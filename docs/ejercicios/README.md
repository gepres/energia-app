# Ejercicios uno por uno

Un documento por ejercicio: qué pidió el taller, qué se eligió en la revisión y cómo se dibuja.

## Grupos y numeración

Desde el 2026-11-12 los 11 ejercicios se agrupan según lo que hace cada uno y se numeran en ese
orden, a pedido del usuario. Antes seguían el orden en que se revisaron en el taller.

La app usa el `id`, no el número. Por eso no cambian las direcciones (`#/ejercicio/<id>`), las
rutinas guardadas ni los audios de la voz.
